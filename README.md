# Mots Fléchés

Jeu de mots fléchés 10×15 jouable sur téléphone, installable comme une appli.

- Séries de 10 grilles générées à la demande, sans répétition des mots déjà vus
- Catégories : classique, League of Legends, jeux vidéo, Twitch / YouTube
- Fonctionne hors connexion une fois installé

**Installer sur Android** : ouvrir le site dans Chrome, menu ⋮ → « Installer l'application ».
